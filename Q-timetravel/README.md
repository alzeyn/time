# Q-timetravel

Образовательный сайт с 360°-панорамами для изучения истории Казахстана.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Структура страницы |
| `style.css` | Оформление |
| `script.js` | Логика сайта |
| `events.js` | Исторические события — **главный файл для редактирования** |
| `images/event-01 … event-10/` | Панорамы |

## Как запустить сайт

Сайт нужно открывать через **Live Server**, а не двойным щелчком по `index.html`. Иначе панорамы не загрузятся.

1. Установите **Visual Studio Code** и расширение **Live Server**.
2. В VS Code выберите **File → Open Folder** и откройте папку `Q-timetravel`.
3. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.

Нужен интернет: библиотека Pannellum подключается из сети.

## Как устроено событие

Каждое событие в `events.js` выглядит так:

```js
{
  title: "Каракумский курултай",
  year: 1710,
  panorama: "images/event-01/image1.png",
  description: "Текст описания.\n\nВторой абзац.",
  references: "Первый источник.\n\nВторой источник."
},
```

- `title` — название события.
- `year` — правильный год (число, без кавычек).
- `panorama` — путь к 360°-панораме.
- `description` — описание. `\n\n` начинает новый абзац.
- `references` — источники. Каждый новый источник начинайте с `\n\n`.

События показываются по порядку, сверху вниз.

## Как добавить событие

1. Положите панораму в папку, например `images/event-10/image10.png`.
2. Скопируйте любой блок `{ ... },` в `events.js` и вставьте после последнего.
3. Измените текст.

Между блоками должна стоять запятая.

Чтобы убрать событие, удалите его блок.

## Панорама

Панорама должна быть сферической, с соотношением сторон **2 : 1** (например, 4096 × 2048 пикселей). Имя файла должно точно совпадать с путём в `events.js`, включая расширение (`.png` или `.jpg`).

## Настройки

В начале `script.js`:

```js
const START_YEAR = 1650; // год, на который возвращается ползунок
const TOLERANCE = 10;    // на сколько лет можно ошибиться
```

Диапазон ползунка меняется в `index.html`:

```html
<input id="year-slider" type="range" min="1400" max="1900" value="1650" oninput="showYear()">
```

## Важно

В текстах не используйте знаки `<` и `>`. Если нужны кавычки внутри текста, используйте « ».
